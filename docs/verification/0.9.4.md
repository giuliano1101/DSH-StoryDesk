# 0.9.4 验收说明

验收日期：2026-11-14。此页为不包含私人作品、模型原始响应、连接配置或本机路径的验收摘要。

## 使用入口

在小说或剧本项目的简报或正文页打开「小说医生 / 剧本医生」，选择人物动机、伏笔回收或悬念信息释放，再选择当前章节 / 分场、当前集（适用的剧本）或整部作品已有材料。模型来自 Harness 实际连接目录。

诊断会读取确定性生成的故事档案、完整有效大纲和容量内的相关正文，并显示覆盖与省略范围。诊断不修改正文；选定的、具有准确证据的意见可以加入助手折叠意见组，用户补充总要求并发送后进入现有改稿流程。待确认问题需先补充依据，不能直接用于自动改写。

## 功能与数据保护

- 三项检查同时支持小说与剧本；区别明确的创作问题、可选建议和上下文不足。
- 人物选择结合目标、代价与转变依据；伏笔结合完结状态及后续计划；悬念区分读者与角色知情差、刻意隐瞒和揭晓顺序。
- 模型提交目标正文的唯一精确引文，服务端定位并保存规范选区；重复、缺失、非精确或越界证据会被拒绝。相关跨场证据同样验证来源。
- 判断分类及依据为独立字段，不从自然语言推测。历史报告与导入数据不进行宽松修复。
- 资料更新会使旧证据失效；生成和写入阶段均检查原文变化。改写采用既有版本与恢复保护。

## 范围与限制

故事档案仅依据保存的设定、已采用资料及有效大纲生成，不会自动将正文推断为世界观。超出上下文容量的正文不会假称已检查；缺少证据时应要求补充。审美意见不等同于客观逻辑错误。诊断结果需由作者判断，现有改稿流程仍保留发送授权和版本保护。

本仓库同步不改变运行中的 Harness，也不附带用户作品、设置密钥、安装包、测试数据或原始模型记录。
