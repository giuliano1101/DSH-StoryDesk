# 剧本医生交接与适配范围

来源为用户提供的 MacBook `script-writing-studio` 完整快照。原始文件保存在 `2026-11-13-script-writing-studio/`，38 个源文件逐一核对 manifest 的字节数与 SHA256；压缩包 SHA256 为 `89ece43cbab8b4c80435d6c3060f39d1a9b137216d48f6fd20122f9fcb1bcc72`。`资产总表.md` 是输出示例名。

原始快照仅作来源留档，不注册为全局技能，也不作为每次调用的整包提示词。运行时使用经产品边界约束的精简适配规则。

| 来源 | 适配用途 |
|---|---|
| SKILL.md、使用手册.md | 任务路由、按需加载、阶段交接、诊断与改写分离 |
| 02-script-doctor、02-startup-workflow | 全作品、单集、单场会诊；已有材料与项目目标为依据 |
| 02-rules-granularity-output、02-panels-examples | 不评分、不捧杀、多视角与分歧、证据、影响与优先级 |
| 02-boundary-interface | 不代替作者裁决；诊断建议回流到显式改稿 |
| 03-dialogue-expert | 人物声音、潜台词、自然口语、表演停顿和信息冗余诊断 |
| 01b-rhythm-matrix | 节奏档位、钩子/信息增量/功能性留白、平台节奏体检 |

小说诊断沿用证据与回流机制，改用叙述视角、人物内心、章节推进等评价维度；这是本项目的适配，原包不含单独的“小说医生”技能。

本次不接入完整项目开发向导、全剧自动扩写、资产制作、摄影动作子库、AI 视频分镜、Seedance 提示词生成或后期音乐生产。这些需要额外资产/视频接入与独立交互，超出本次诊断工作流；原始资料仍完整保留，供后续按需选择。

源文件中的平台秒数、图片数量、分辨率和提示词上限不作为已验证接口能力。当前没有在本任务接入视频生产端，因此不展示或发送这些生成参数。诊断中的前3/15/30秒仅为创作观察维度；没有时间信息时应明确无法对应，不虚构时间点，不把创作经验当成平台硬规则，也不承诺流量。

修改范围限定创作工作台 `screenwriter-desk/`。父项目中另一会话的 `src/script-doctor*.js`、`client/script-doctor*`、账号和版本代码均不覆盖。本次不安装、不重启、不切换真实前台、不推送或公开发布。

报告随项目持久化、可随 JSON 导出。报告中的引用在服务端核对原文及范围，变更依据后禁止移交。导入报告以及后端重新启动前的报告作为只读历史，重新诊断可获得新的移交能力；同一后端会话内普通页面刷新仍可继续移交。该边界用于避免导入数据或旧报告重放写入权限，不会自动重放诊断或改稿。
