# Roadmap / 路线图

This is a direction, not a delivery promise. Priorities depend on author feedback and maintainers' capacity.

## Available in 0.9.4

- Novel and screenplay projects, episode-aware structure, local writing, backups and versions.
- Context-aware assistant popup, role / Skill configuration, exact paragraph opinions and guarded rewriting.
- Story bible, continuity review and motivation / payoff / suspense diagnostics for both formats.
- Verified Harness tarball distribution with checksum files.

## Next priorities

- Full interface localization: extract strings, choose a locale, translate role defaults and preserve project-language choices. README translations alone do not implement this.
- A broader compatibility matrix across current Harness builds and additional desktop systems.
- More diverse author-approved diagnosis samples, long-work coverage explanations and evaluation of false positives.
- Accessibility and keyboard navigation review for writing and diagnosis flows.
- Better portable onboarding for backup / import and safe updates.

## Explore after validation

- Optional plugin-index distribution once licensing, host requirements and public release metadata are reviewed. Current npm `private: true` intentionally prevents accidental npm publication; it also affects official plugin-index discovery.
- Additional export and editorial workflows based on real demand.

No promise of automatic cloud sync, autonomous irreversible editing or guaranteed creative quality. Propose a focused improvement through [contributing](../CONTRIBUTING.md).
