# Support / 获取帮助

Start with [installation](docs/installation.md), the [Chinese user guide](docs/user-guide.zh-CN.md) and [release notes](CHANGELOG.md).

- Installation failures, regressions and data problems: [bug report](https://github.com/giuliano1101/DSH-StoryDesk/issues/new/choose).
- Workflow improvements, translations and accessibility: [feature request](https://github.com/giuliano1101/DSH-StoryDesk/issues/new/choose).
- Questions and sharing experiences: [GitHub Discussions](https://github.com/giuliano1101/DSH-StoryDesk/discussions), if enabled.
- Vulnerabilities and credentials: [private security reporting](SECURITY.md).

Please provide StoryDesk version, Harness version, operating system, active profile, expected result, actual result and minimal reproduction with fictional text. Redact paths, personal information and secrets before attaching logs or screenshots. Do not attach full private project backups to public issues.

中文、English、日本語 descriptions are welcome. Community support is best-effort; no commercial support or response time is promised. We cannot guarantee another model provider's judgment, availability or pricing.
